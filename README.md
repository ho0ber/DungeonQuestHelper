# DungeonQuestHelper
A simple addon to help prepare for dungeon quests in WoW: Forever

## AI Usage Disclosure & Disclaimer
Because the nature of this addon is to save me, personally, time on manual research for dungeon prep, I have elected to use Claude Code heavily to collect quest information and requirements, and also to update and test the addon.

While I normally put a lot of rigor into reviewing and testing code I publicly release, the low risk nature of simple WoW addons allows me to be a bit lax in this case. I have reviewed all addon code to determine performance impacts in game, but I have not reviewed all of the data the addon presents or confirmed its accuracy.
